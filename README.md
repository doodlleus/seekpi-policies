# SeekPi app policies

| App | Privacy policy |
| --- | --- |
| Pocket Tracer | https://doodlleus.github.io/seekpi-policies/pocket-tracer/privacy/ |

## Adding an app

1. Copy `pocket-tracer/privacy/index.html` to `<app-name>/privacy/index.html` and rewrite it for the new app.
2. Add the app to `index.html` and to the table above.
3. Push to `main`. GitHub Pages publishes the change within a minute or two.

Keep each URL stable once it is in a store listing. If a policy changes, update the page and its effective date rather than moving it.
